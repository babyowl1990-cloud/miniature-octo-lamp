Module 1

Zero‑Click Search (Answers Without Clicking)

Zero‑click search means you type a query and get the answer directly on the search results page (SERP). This saves time and works well on slow school computers.

Useful Zero‑Click Patterns

  • define osmosis — dictionary box with a short definition.
  • what is photosynthesis — knowledge panel with explanation.
  • population of Canada — fact card with the latest number.
  • solve 2x+5=15 — calculator and step‑by‑step solution.
  • 5 miles in km — unit conversion box.
  • diagram of water cycle — image strip with labeled diagrams.

Practice Tasks

  • Get a one‑sentence definition of osmosis without clicking any website.
  • Find the year Einstein was born using only the SERP.
  • Convert 5 miles to kilometers using the conversion box.

Speed Tip: Use Ctrl + F to search inside the SERP for specific words (like “definition” or “population”).

Module 2

Google Dorking (Beginner, Safe, School‑Friendly)

Google Dorking is not hacking. It uses special search operators to filter public information that Google already indexes. Here we only use safe, student‑friendly examples.

Core Operators

site:      limit results to a specific website or domain
filetype:  search for a specific file type (pdf, doc, ppt)
intitle:   search for words in the page title
inurl:     search for words in the URL
intext:    search for words in the page text
"..."      search for an exact phrase

Student‑Friendly Examples

  • Find government PDFs about climate change:
    site:.gov filetype:pdf "climate change"
  • Find public math practice worksheets:
    filetype:pdf "math practice"
  • Find university pages about the civil rights movement:
    site:.edu "civil rights movement"
  • Find open image directories (use only safe examples your teacher approves):
    intitle:"index of" "images"

Practice Tasks

  • Find a .gov PDF about volcanoes using site:.gov filetype:pdf.
  • Find a .edu article explaining photosynthesis.
  • Find a public PDF that contains the word “budget”.

Speed Tip: Use Ctrl + L to jump directly to the browser address/search bar, then type your dork.

Module 3

School‑Friendly OSINT Sources

Not all websites are equal. For school research, focus on trusted domains and educational portals that teachers and librarians recommend.

Trusted Domains & Portals

  • .gov — NASA, CDC, National Archives, government fact sheets.
  • .edu — university pages, open courses, research summaries.
  • Library of Congress — historical documents and timelines.
  • Smithsonian — science, history, and culture resources.
  • Britannica School — student‑friendly encyclopedia articles.
  • National Geographic Kids — geography, animals, environment.

Safe Search Patterns

  • site:.gov "water cycle" — government explanations of the water cycle.
  • site:.edu "ancient Egypt" — university pages about ancient Egypt.
  • "timeline of WW2" kids — child‑friendly timelines and summaries.

Practice Tasks

  • Find a government fact sheet about hurricanes using site:.gov.
  • Find a university explanation of mitosis using site:.edu.
Module 4

Offline OSINT (No Internet Required)

Many students have limited internet or blocked websites. Offline OSINT teaches how to research using physical resources and people around you.

Offline Sources

  • Textbooks and workbooks provided by the school.
  • Encyclopedias and reference books in the library.
  • Magazines and journals for current events and science topics.
  • Teacher handouts, worksheets, and printed guides.
  • Interviews with teachers, librarians, and local experts.

Offline Research Workflow

  • Define the question — e.g., “What caused World War I?”
  • Use the index — look up “World War I” or “causes” in the back.
  • Scan headings — read section titles and subheadings.
  • Collect facts — write down dates, events, and key causes.
  • Cross‑check — compare information from two different sources.

Practice Tasks

  • Use a textbook index to find the section on ecosystems.
  • Compare two offline sources about the same topic and list similarities.

Speed Tip: Use sticky notes or page flags as offline bookmarks to mark important pages quickly.

Module 5

Speed Shortcuts (Keyboard‑Based OSINT)

Keyboard shortcuts help you move faster on school computers, especially when the mouse is slow or the trackpad is hard to use.

Browser Shortcuts

Ctrl + T New tab
Ctrl + W Close tab
Ctrl + Shift + T Reopen closed tab
Ctrl + Tab Switch to next tab
Ctrl + L Jump to address/search bar
Ctrl + F Find text on the page

Text Shortcuts

Ctrl + C Copy
Ctrl + V Paste
Ctrl + X Cut
Ctrl + A Select all
Ctrl + Z Undo
Ctrl + Y Redo

Windows Shortcuts

Alt + Tab Switch between apps
Win + D Show desktop
Win + Shift + S Open screenshot tool

Practice Tasks

  • Open three tabs and switch between them using only keyboard shortcuts.
  • Reopen a closed tab using Ctrl + Shift + T.
  • Take a screenshot of a search result using Win + Shift + S.

Practice Zone (Hands‑On Training)

Use this section as a checklist or mini‑test. Students can work through each challenge to prove they understand the techniques.

Zero‑Click Challenges

  • Find the current weather for your city without clicking any website.

Google Dorking Challenges

  • Find a worksheet PDF using filetype:pdf "worksheet".

Offline Challenges

Shortcut Challenges
