### 1. Concept of the tactical OSINT website tool

This “tool” is a **website hub** that teaches students how to do **OSINT‑style research** *without AI*, using:

- **Zero‑click search** (answers from the results page itself)  
- **School‑friendly online sources**  
- **Offline methods** (books, experts, library systems)  
- **Keyboard shortcuts** to move fast and stay efficient  

Think of it as a **training ground**: every page is a small module with examples, exercises, and shortcut tips.

---

### 2. Zero‑click search techniques (no AI, no external clicks)

#### 2.1 What zero‑click means

**Zero‑click search:** you type a query, and you get the answer **on the search results page (SERP)** without opening any site.

**Use it for:**

- **Definitions:**  
  - Query: `define osmosis`  
- **Quick facts:**  
  - Query: `population of Canada`, `Einstein birth year`  
- **Math & science:**  
  - Query: `solve 2x + 5 = 15`  
  - Query: `speed = distance / time example`  
- **Conversions:**  
  - Query: `5 miles in km`, `3 cups to ounces`  

#### 2.2 Query patterns that trigger zero‑click answers

- **“what is ___”** → definitions, short explanations  
- **“definition of ___”** → dictionary box  
- **“formula for ___”** → math panels  
- **“steps of ___”** → process snippets  
- **“___ summary”** → short overviews  
- **“diagram of ___”** → images on SERP  

Your website can show **example screenshots** and a **practice section**:

- **Exercise:**  
  - Task: “Get a one‑sentence definition of *photosynthesis* without clicking any site.”  
  - Hint: Use `what is photosynthesis` or `define photosynthesis`.

### 3. School‑friendly OSINT web methods

#### 3.1 Safe domains to teach

On the site, list **trusted, school‑friendly domains**:

- **Government & institutions:**  
  - **`.gov`** (CDC, NASA, National Archives)  
  - **`.edu`** (university pages, open courses)  
- **Reference portals:**  
  - Britannica School  
  - National Geographic Kids  
  - Library of Congress  
  - Smithsonian resources  
- **Library tools:**  
  - School **LibGuides**  
  - Online catalog (OPAC)  
  - Teacher‑curated link lists  

#### 3.2 OSINT‑style search operators (non‑AI)

Teach simple operators:

- **Exact phrase:**  
  - Query:  
    \["water cycle diagram"\]  
- **Site filter:**  
  - Query:  
    \[site:.gov "climate change facts"\]  
- **Domain filter:**  
  - Query:  
    \["civil rights movement" site:.edu\]  

Each operator gets:

- **Explanation**  
- **Example query**  
- **Student exercise**

### 4. Offline research module

This part of the website explains **how to research with no internet**.

#### 4.1 Core offline sources

- **Textbooks:**  
  - Use **index**, **table of contents**, **chapter summaries**, **glossary**.  
- **Library books & encyclopedias:**  
  - Topic overviews, timelines, definitions.  
- **Magazines & journals:**  
  - Current events, science, social issues.  
- **Expert interviews:**  
  - Teachers, librarians, local professionals.  

#### 4.2 Simple offline OSINT workflow

1. **Frame the question:**  
   - “What caused WWI?”  
2. **Pick sources:**  
   - History textbook + library encyclopedia.  
3. **Scan structure:**  
   - Use index: `World War I`, `causes`.  
4. **Extract facts:**  
   - Note dates, key events, main causes.  
5. **Cross‑check:**  
   - Compare textbook vs encyclopedia.  

Your site can include **printable checklists** and **note templates**.

### 5. Keyboard shortcuts module (speed layer)

This is the “speed boost” page—students learn shortcuts that make all of this faster.

#### 5.1 Browser & tab shortcuts

- **Open new tab:**  
  - **Ctrl + T**  
- **Close tab:**  
  - **Ctrl + W**  
- **Reopen closed tab:**  
  - **Ctrl + Shift + T**  
- **Switch tabs:**  
  - **Ctrl + Tab** (forward), **Ctrl + Shift + Tab** (back)  
- **Refresh page:**  
  - **Ctrl + R** or **F5**  
- **Find on page:**  
  - **Ctrl + F** (search within long articles/SERPs)  

#### 5.2 Text & selection shortcuts

- **Select all:**  
  - **Ctrl + A**  
- **Copy:**  
  - **Ctrl + C**  
- **Paste:**  
  - **Ctrl + V**  
- **Cut:**  
  - **Ctrl + X**  
- **Undo / Redo:**  
  - **Ctrl + Z** / **Ctrl + Y**  

#### 5.3 Window & navigation shortcuts (Windows)

- **Switch apps:**  
  - **Alt + Tab**  
- **Minimize all (show desktop):**  
  - **Win + D**  
- **Screenshot (region):**  
  - **Win + Shift + S**  

Your website can show:

- A **shortcut cheat sheet**  
- Small **practice drills** (e.g., “Open three tabs and switch between them only with the keyboard”).
